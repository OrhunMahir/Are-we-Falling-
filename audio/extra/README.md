# Audio options (ElevenLabs)

Extra sounds made on 14 November 2026 for the intruder seat and as options for everything else in the game. Nothing here is loaded unless the code asks for it, so it does not slow the game down. Most names come in two takes, `_a` and `_b`: pick the one you like and copy it to `audio/<name>.mp3`, or randomise between them.

The `alt_*` voice takes are re-recorded without the old "Kara Kutu" callsign, with new voices (captain: British airline pilot, tower: clear PA voice, crew: young female, passengers: five different characters, warning system: robotic).

If the itch.io zip gets too big, leave this folder out of the package; the game itself only needs the files in `audio/`.
